# Contexto do Operador

## Negócio
- **Produto:** PátioVivo™ — infraestrutura de crescimento com IA para lojas de seminovos/usados
- **Modelo:** SaaS + setup fee
- **Estágio:** Pivô — migrando de [negócio anterior] para este nicho
- **Canal principal:** Venda direta (outbound) + tráfego pago (Meta Ads)

## Posicionamento
- Não é só software de gestão — é infraestrutura de crescimento com IA
- Diferencial: SDR IA que atende lead em < 60s, 24/7, no WhatsApp do cliente
- Gap do mercado: concorrentes (Revenda Mais, BNDV, etc.) resolvem operação, não vendas com IA

## ICP Target
- Lojas independentes de seminovos/usados, Brasil
- Foco inicial: Persona 1 (Dono de Pátio) + Persona 2 (Tá Tentando)
- Decisor: dono da loja (pessoa física, normalmente homem, 30–55 anos)

## Linguagem da marca
- Direta, sem bullshit, sem jargão de tech
- Fala de R$ e resultados concretos
- Tom: consultor experiente do setor, não vendedor de software
